# Квася, ням!

HTML5-игра для Яндекс Игр: лягушка Квася ловит мух языком, копит звёзды и открывает наряды.

Играть: https://anastasiyabo-bit.github.io/kvasyanya/

Репозиторий хранит исходники и историю итераций.

## Стек

- Phaser 3.90
- TypeScript
- Vite

## Запуск

```bash
npm install
npm run dev
```

Игра откроется на `http://127.0.0.1:5173/`.

## Сборка

```bash
npm run build
npm run zip
```

`npm run zip` собирает архив для загрузки в Яндекс Игры.
